This directory contains the professional frontend of the **Kleer Infini** B2B platform. It is designed to provide a premium, smooth, and high-conversion user experience for global exporters and buyers.

---

## ✨ Features & Architecture

### 💎 UI/UX Design System
- **Custom Design System**: Built with Tailwind CSS for maximum consistency and speed.
- **Glassmorphism & Gradients**: Modern aesthetic that reflects professionalism and quality.
- **Responsive Mastery**: Fully optimized for mobile, tablet, and desktop screens.
- **Micro-animations**: Enhanced engagement using Framer Motion for smooth transitions and hover effects.

### 🌐 Internationalization (i18n)
- **Multi-language Support**: Fully integrated with `react-i18next`.
- **Supported Languages**: French, English, Arabic, Spanish.
- **Dynamic RTL Support**: Ready for Arabic interface requirements.

### 📁 Structure
- `/src/components`: Atomic and reusable UI components.
- `/src/pages`: Main application routes (Home, Producers, Login, etc.).
- `/src/assets`: Optimized images and brand assets.
- `/src/utils`: Helper functions and shared logic.

---

## 🛠️ Development

### Setup
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
